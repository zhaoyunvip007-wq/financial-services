# A 股大宗交易分析

## 什么是大宗交易

大宗交易（Block Trade）= 单笔成交规模较大、不通过集中竞价撮合的场外交易。沪深交易所规定：

- **单笔成交金额 ≥ 200 万元**（部分股票门槛更高）
- **价格区间**：当日收盘价的 ±10%（创业板 / 科创板 ±20%）
- **披露时点**：交易日盘后由交易所披露
- **结算时间**：交易日 T+1 资金到账

**为什么要分析大宗交易？**

1. **股东减持的主渠道**：减持新规约束竞价，PE / VC / 大股东多通过大宗减持
2. **机构调仓的痕迹**：保险、社保、QFII 之间的大额调仓常通过大宗
3. **折溢价透露态度**：折价大 = 卖方急于出货；溢价 = 买方主动接盘
4. **接盘方判断**：买方营业部决定后续股价走向（机构接盘看好 / 散户托盘出货）

### Step 2：核心维度分析

**A. 折溢价**
- **折价（< 收盘价）**：常见，反映卖方愿意让利出货
  - 折价 0-3%：正常机构调仓
  - 折价 3-7%：阶段性减持，温和压力
  - 折价 7-10%（接近跌停）：急于出货，警惕
- **溢价（> 收盘价）**：罕见但有特殊含义
  - 溢价 0-3%：买方主动锁筹
  - 溢价 > 5%：资本运作（如举牌、控制权争夺）

**B. 卖方席位识别**

| 席位类型 | 判断 |
|---|---|
| **大股东 / 实控人** | 公告披露，常见 |
| **PE / VC 机构** | 解禁后高频出现 |
| **基金管理公司** | 公募基金调仓 |
| **券商自营** | 套保 / 调仓 |
| **个人股东（实名）** | 股权激励解锁后 |

**C. 买方席位识别（更重要）**

| 买方类型 | 信号意义 |
|---|---|
| **机构席位** | 强信号，说明机构接力 |
| **知名游资营业部** | 短期博弈，看接盘游资风格 |
| **保险 / 社保 / 险资席位** | 长线配置，正面信号 |
| **量化席位** | 不构成信号 |
| **散户营业部** | 警惕"出货式接盘" |

**D. 同一标的多笔大宗交易**
- 一日内出现 5+ 笔大宗 = 大额减持 / 大股东集中处置
- 连续 3 日大宗交易 = 有计划性的减持
- 单笔超过流通股 1% = 控股权转让 / 战略调整

### Step 3：常见模式与解读

**模式 1：解禁后大股东减持**
- 标志：解禁日 + 5 日内出现大宗 + 卖方为大股东
- 折价：通常 5-7%
- 操作建议：阶段性回避

**模式 2：机构调仓**
- 标志：买卖双方都是机构席位 + 折价 1-3%
- 解读：基金间申赎导致的被动调仓，不构成方向判断
- 操作建议：忽略

**模式 3：举牌前奏**
- 标志：连续大宗交易 + 买方为单一机构 + 接近收盘价或溢价
- 解读：可能是举牌方在收集筹码，5% 临界点前会发举牌公告
- 操作建议：关注后续公告，可能有控制权变更

**模式 4：员工持股 / 股权激励解锁**
- 标志：卖方为高管 / 核心员工 + 买方多为机构 + 折价 3-5%
- 解读：员工兑现激励，对股价影响有限
- 操作建议：观察机构接盘方，如果是知名机构则正面

**模式 5：实控人变更**
- 标志：单笔大宗交易 ≥ 5% + 协议转让性质
- 解读：实控人将股权过户给新股东
- 操作建议：注意公告，新实控人可能带来新业务方向

## 重要提示

- **不要单看折价**：折价大有时是刻意做出来给市场看的，配合公告分析才有价值
- **接盘方比卖方更重要**：谁卖出有公开动机，谁买入暗含态度
- **大宗交易 T+1 解禁**：买方可能很快卖出，警惕"过桥式接盘"（中介帮忙完成减持）
- **实控人协议转让**：单笔大宗 ≥ 5% 通常需要预披露，公告有 6 个月禁售期
- **业绩窗口期警惕**：业绩公告前 30 天内的大宗交易，可能是知情人提前减持
- **回购对冲影响**：公司同时启动回购的大宗减持，不一定是负面信号
- **大宗不影响 K 线**：大宗交易不计入当日成交量，但会反映在持股变动上
