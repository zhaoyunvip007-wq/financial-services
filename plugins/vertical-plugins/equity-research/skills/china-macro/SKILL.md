# 中国宏观经济数据与板块影响

## 工作流

### Step 1：跟踪核心指标

**月度高频指标（最重要）**

| 指标 | 发布时点 | 发布机构 | 解读重点 |
|---|---|---|---|
| **制造业 PMI** | 月末（约 31 日） | 国家统计局 | 50 荣枯线：扩张 / 收缩 |
| **财新制造业 PMI** | 月初（约 1 日） | 财新 / 标普 | 偏中小企业，与统计局 PMI 互补 |
| **CPI（居民消费价格）** | 次月 9-10 日 | 国家统计局 | 通胀压力 / 消费力 |
| **PPI（工业生产者价格）** | 次月 9-10 日 | 国家统计局 | 上游成本 / 工业景气 |
| **社融存量 + M2** | 次月 10-15 日 | 中国人民银行 | 货币宽松度 / 实体融资需求 |
| **新增人民币贷款** | 同上 | 中国人民银行 | 短期 / 中长期贷款结构 |
| **进出口（美元 / 人民币）** | 次月 7-15 日 | 海关总署 | 外需 / 出口链景气 |
| **固定资产投资（FAI）** | 次月 15-18 日 | 国家统计局 | 制造业 / 基建 / 地产投资 |
| **社会消费品零售（社零）** | 次月 15-18 日 | 国家统计局 | 消费动能 |
| **工业增加值** | 次月 15-18 日 | 国家统计局 | 制造业产出 |

**季度指标**
- **GDP**：季后 20 天左右（如 Q1 数据 4 月 16 日左右）
- **居民收入与支出**：季度披露

**利率与汇率（实时）**
- **LPR 利率**：每月 20 日（央行公告）
- **MLF 利率**：每月 15 日（中期借贷便利）
- **逆回购利率**：每日（央行公开市场操作）
- **人民币汇率（USDCNY、CNY 对一篮子）**：实时

### Step 2：数据获取

通过 AKShare MCP：

```python
# 国家统计局月度数据
ak.macro_china_pmi()  # 制造业 / 非制造业 PMI
ak.macro_china_cpi_yearly()  # CPI 同比
ak.macro_china_ppi_yearly()  # PPI 同比

# 央行数据
ak.macro_china_money_supply()  # M0/M1/M2
ak.macro_china_shrzgm()  # 社融存量
ak.macro_china_lpr()  # LPR 历史

# 海关数据
ak.macro_china_exports_yoy()  # 出口同比
ak.macro_china_imports_yoy()  # 进口同比

# 统计局综合
ak.macro_china_gdp_yearly()  # GDP 季度
ak.macro_china_market_margin_sh()  # 两融余额（市场情绪）
ak.macro_china_fdi_data()  # FDI 实际使用外资
```

### Step 3：板块映射（宏观 → 申万行业）

每个宏观指标对申万板块的影响传导：

**制造业 PMI**
- 上行（> 50）：周期股（钢铁、化工、有色、机械）受益
- 下行（< 50）：防御板块（公用事业、银行、必选消费）跑赢

**CPI（通胀）**
- CPI 上行 + PPI 上行：上游传导，化工 / 有色 / 资源股受益
- CPI 上行 + PPI 下行：消费品涨价，食品饮料 / 农林牧渔受益（猪周期等）
- CPI 下行：消费板块承压

**PPI（工业品价格）**
- PPI 上行：上游受益（煤炭、有色），下游成本压力（家电、汽车）
- PPI 下行：上游承压，下游受益

**社融 + M2（流动性）**
- 社融超预期：成长股（科创板、创业板、医药、TMT）受益
- 社融低于预期：高股息（银行、煤炭、公用）防御

**新增贷款结构**
- 中长期贷款增多：制造业投资意愿强（受益设备、机械）
- 居民中长期贷款（按揭）增多：地产 / 家居 / 家电
- 短期贷款增多：货币政策传导不畅，警惕

**LPR / MLF（利率）**
- 降息：高股息（房地产、银行）+ 成长股双受益
- 加息：估值收缩，所有板块承压

**进出口**
- 出口超预期：出口链（消费电子、纺织服装、轻工、机械、汽车零部件）
- 出口疲软：内需为主板块（必选消费、医疗、电力公用）

**固定资产投资 FAI**
- 制造业投资强：自动化设备、半导体设备、机器人
- 基建投资强：建筑、建材、工程机械、工程服务
- 地产投资强：地产、家居、家电、白电

**社零**
- 餐饮 + 服装强：可选消费（白酒、化妆品、服装、家电）
- 必选品强：必选消费（食品、调味品、医药）

**工业增加值**
- 高新技术工业增加值高：电子 / 电力设备 / 计算机
- 制造业增加值高：传统制造（机械、汽车、钢铁）

### Step 4：政策事件追踪

**重要政策窗口（必跟踪）**

- **中央经济工作会议**：每年 12 月，定调来年经济政策
- **两会**：每年 3 月，全年政策框架公布（GDP 目标、CPI 目标、赤字率）
- **政治局会议**：4 / 7 / 10 / 12 月，季度经济政策定调
- **央行货币政策执行报告**：季度
- **国常会议**：每周或不定期，具体政策出台
- **发改委 / 工信部 / 财政部专题文件**：行业政策直接影响

```
中国宏观数据 - 2026 年 4 月数据点评
（数据公布日 2026-05-06）

【关键数据汇总】
- 制造业 PMI：49.8（上月 50.4）→ 跌入收缩区间
- 财新 PMI：50.5（上月 51.2）
- CPI 同比：+0.3%（上月 +0.5%）→ 通胀温和
- PPI 同比：-2.1%（上月 -1.8%）→ 工业品价格承压
- 社融存量同比：+8.3%（上月 +8.5%）
- 新增贷款：1.2 万亿（上月 1.8 万亿）
- 出口同比（人民币）：+5.2%（上月 +7.1%）

【综合判断】
经济温和复苏中段，制造业回落但服务业稳定。CPI 温和但 PPI 持续负值，反映需求端偏弱。
信贷数据走弱，央行可能继续宽松（5 月 LPR 下调概率上升）。

【板块影响】
正面（建议关注）：
- 银行：社融数据印证"宽货币 + 信贷支持"，估值修复
- 公用事业：经济偏弱期防御属性突出
- 高股息（煤炭 / 钢铁）：现金流稳定，分红吸引力上升
- 出口链（部分）：出口仍正增长，关注消费电子

负面（建议规避）：
- 周期上游：PPI 持续负值，化工 / 有色短期承压
- 顺周期消费：CPI 走弱反映消费力疲软，可选消费回避

中性：
- TMT / 医药：流动性宽松利好，但需等待业绩兑现
- 新能源：政策支持但产能过剩压制估值

【后续观察】
- 5 月 20 日 LPR 是否下调
- 6 月初 5 月 PMI 数据
- 6 月中旬 5 月社融
- 7 月中政治局会议政策定调
```

## 重要提示

- **数据公布前后波动大**：PMI / CPI / 社融公布日的盘中波动不可预测，避免短线博弈
- **环比 vs 同比**：A 股看习惯看同比，但环比对短期判断更敏感
- **季节性调整**：春节前后数据失真，看历史季节性
- **中国 / 财新 PMI 差异**：统计局偏大企业、财新偏中小企业，分歧时关注小企业景气
- **GDP 季度数据有水分**：GDP 平减指数等技术处理不透明，看分项数据更准
- **政策预期重于数据**：A 股是政策市，数据是结果，政策预期才是定价核心
- **海外联动**：美联储、美国 CPI、美元指数对 A 股北向资金有传导
