# A 股龙虎榜分析

## 什么是龙虎榜

龙虎榜（Dragon Tiger List, DTL）是沪深交易所每个交易日盘后披露的异常交易公开信息，主要披露：
- 当日涨跌幅 ±7%（创业板/科创板 ±15%）的股票前 5 大买卖营业部席位
- 当日换手率达 20% 的个股
- 当日成交量异常的股票

数据是 A 股**主力资金行为**的核心透明窗口，对短线交易、热点跟踪极有参考价值。

## 工作流

### Step 1：数据获取

通过 AKShare MCP 调用：
```python
# 获取最近交易日龙虎榜
ak.stock_lhb_detail_em(start_date="2026-05-06", end_date="2026-05-06")
# 获取个股龙虎榜历史
ak.stock_lhb_stock_detail_em(symbol="600519", date="2026-05-06")
# 获取机构席位明细
ak.stock_lhb_jgmmtj_em(start_date="2026-05-06", end_date="2026-05-06")
```

如 AKShare 不可用，回退到东方财富数据中心：
- 龙虎榜首页：data.eastmoney.com/stock/lhb.html
- 营业部明细：data.eastmoney.com/stock/tradedetail.html

### Step 2：席位类型识别

每个上榜席位归类：

| 席位类型 | 识别特征 | 解读 |
|---|---|---|
| **机构席位（一/二/三/四/五）** | 名称为"机构专用席位 X 号" | 公募 / 私募 / 险资，行为偏中线，连续买入 = 看好 |
| **知名游资席位** | 如"中信证券上海溧阳路""华泰证券深圳益田路荣超商务中心""国泰君安上海江苏路" | 短线博弈派，关注情绪和题材 |
| **量化席位** | 如"招商证券深圳分公司""华鑫证券上海分公司"（部分） | 高频交易，对个股影响存疑 |
| **散户营业部** | 普通券商分支 | 跟风为主，无信号价值 |
| **北向资金（陆股通）** | "深股通专用""沪股通专用" | 外资动向，长线配置 |

### Step 3：核心分析维度

**a. 单日资金净流向**
```
净买入 = 买入金额 - 卖出金额
机构净买入 = Σ机构席位净买入
游资净买入 = Σ知名游资席位净买入
```

**b. 历史胜率**
- 知名游资有相对稳定的"风格标签"（追龙头 / 抄底 / 接力）
- 用 AKShare `stock_lhb_yyb_detail_em()` 拿营业部历史业绩
- 关注：近 3 月、近 1 年的盈亏概率与平均收益

**c. 资金属性判断**
- **机构集中流入** + **游资跟风**：通常逻辑较扎实，可能催化中线行情
- **纯游资接力**：题材炒作，注意快进快出
- **机构卖出 + 游资买入**：分歧加剧，警惕高位接盘
- **机构买入 + 游资卖出**：可能是底部建仓信号

**d. 涨停板特征**
- 一字板上龙虎榜（开盘即封死涨停）= 极强势，资金抢筹
- 炸板回封 = 分歧加大
- 反复打开涨停 = 主力出货嫌疑

### Step 4：异常信号扫描

每日龙虎榜必查的几类信号：

🚩 **机构组团扫货**：3+ 机构席位同时买入 → 重点关注，常预示中线行情
🚩 **顶级游资接力**：知名游资连续 2-3 日上榜买入 → 题材发酵期
🚩 **高位放量大跌**：大额机构卖出 + 游资买入 → 大概率"机构出货游资接盘"
🚩 **次新股龙虎榜**：上市 6 月内频繁上榜 = 控盘度异常
🚩 **同一席位反复操作**：日内净买入 → 隔日净卖出 = 试盘 / 拉高出货

### Step 5：输出格式

**当日龙虎榜复盘**：

```
2026-05-06 龙虎榜复盘

【上榜股票数】X 只
【机构净买入前 5】
1. 公司名（代码）— 净买入 X.XX 亿元 — [行业] — 涨跌幅 +X%
   买方：3 机构席位 + 1 游资席位（XXX）
   逻辑：[行业景气 / 业绩超预期 / 政策催化]

【游资接力标的】
1. 公司名（代码）— XX 营业部连续 2 日买入 — 涨幅 +XX%
   游资风格：[追龙头型 / 题材接力型 / 妖股开板型]
   建议：[关注 / 跟踪 / 规避]

【高度警惕】
1. 公司名（代码）— 机构卖出 X 亿 + 游资买入 X 亿 — 涨幅 +XX%
   信号：机构出货游资接盘，谨防补跌

【次日候选】
基于今日龙虎榜，明日值得跟踪：
- 行业 / 主题 1：原因
- 行业 / 主题 2：原因
```

## 重要提示

- **龙虎榜只是当日异动信号**，不构成交易建议。要结合基本面和技术面判断
- **机构席位也会做错**：不要把"机构买入"等同于"逻辑成立"，机构同样有羊群效应
- **游资跟单风险高**：知名游资的"反向利用"现象普遍，公开后散户跟风，游资借机出货
- **量化席位干扰**：部分龙虎榜显示的"机构席位"是量化做 T0/T+1，不代表中线判断
- **数据时效性**：龙虎榜是盘后披露，次日开盘前所有人都能看到，已有定价反映
- **A 股特有现象**："连板亲儿子"模式（同一游资连续操作连板股）在 2024-2026 年频繁出现，是市场情绪指标
- **节假日数据滞后**：周五龙虎榜要等到下周一才发酵，注意时点
