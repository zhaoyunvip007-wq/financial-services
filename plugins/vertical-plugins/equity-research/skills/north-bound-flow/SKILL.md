# A 股北向资金流向分析

## 什么是北向资金

北向资金 = 通过沪深港通（陆股通）从香港流入 A 股的境外资金，由 QFII / 外资公募 / 海外对冲基金 / 主权基金等组成。被市场视为"聪明钱（smart money）"，因为：

- 决策方为成熟市场机构投资者，配置周期较长
- 重仓白马股，与公募基金重合度高，但调仓更早
- 数据公开透明（每日盘后披露持股、当日盘中实时净流入）
- 历史回测显示对中线行情有一定领先性

**注意**：2024 年起交易所对北向资金披露频率有调整（不再实时披露盘中数据），但持仓变动和资金流向数据仍每日 / 每周公开。

## 工作流

### Step 1：数据获取

通过 AKShare MCP 调用：

```python
# 北向资金每日净流入
ak.stock_hsgt_north_net_flow_in_em(symbol="北上")
# 北向持股个股明细
ak.stock_hsgt_hold_stock_em(market="north", indicator="今日排行")
# 北向行业持仓
ak.stock_hsgt_board_rank_em(symbol="北向资金增持行业排行", indicator="今日")
# 历史持股变动
ak.stock_hsgt_individual_em(stock="600519")
```

### Step 2：核心维度分析

**a. 总量层面**
- 当日净流入金额（亿元）
- 近 5 日 / 20 日累计净流入
- 净流入连续性（连续买入天数 vs 连续卖出天数）
- 当月累计净流入与历史对比

**b. 行业层面**
- 申万一级行业净买入 TOP 5 / 净卖出 TOP 5
- 持仓行业集中度（CR5 / CR10）
- 行业持股市值变化（TWAP 调整后）

**c. 个股层面**
- 单日净买入 TOP 20（绝对金额）
- 单日净买入占流通股比例 TOP 20（相对力度）
- 持股集中度上升前 10（外资抱团）
- 持股集中度下降前 10（外资减持）

**d. 行为模式**
- 外资风格：偏好高 ROE、低负债、稳定分红的核心资产
- 主要重仓：白酒（贵州茅台、五粮液）、消费电子（立讯精密、工业富联）、新能源（宁德时代、阳光电源）、医药（恒瑞、迈瑞）、银行（招商银行、平安银行）

### Step 3：信号识别

**正向信号（关注买入）**：

🟢 **底部连续净流入**：市场调整期，连续 5 日以上净流入 + 单日 > 50 亿 → 外资抄底信号
🟢 **新增重仓**：某只股票 30 天内被买到流通股 5%+ → 配置型买入，中线持有
🟢 **行业集中流入**：单一行业连续 2 周净买入 → 行业景气拐点信号
🟢 **个股北向 + 龙虎榜机构**：北向流入 + 龙虎榜机构买入 → 双重确认

**负向信号（警惕卖出）**：

🔴 **连续大额流出**：5 日累计净流出 > 200 亿 → 外资风险偏好下降
🔴 **重仓股集中减持**：消费 / 医药龙头同步遭减持 → 风格切换前兆
🔴 **持股市值占总市值高位减仓**：从 6%+ 下降到 4% 以下 → 中线趋势可能反转
🔴 **MSCI 调样前减持**：MSCI 季度调样前一个月，被剔除标的会被动卖出

### Step 4：北向资金的局限性

不要把北向资金当作神

❌ **盘中实时数据已不公开**（2024 年规则变化），盘后才能看到全貌
❌ **资金属性混杂**：陆股通包含 QFII / 海外公募 / 海外对冲 / 部分内资借道，"聪明钱"含金量被高估
❌ **量化高频交易占比不低**：部分流入实际上是高频策略，不代表配置观点
❌ **指数被动跟踪资金**：MSCI / FTSE 调样会带来被动买卖，不代表主动判断
❌ **过度跟单风险**：散户广泛跟踪后，北向资金的"先发优势"被削弱
❌ **黑天鹅风险**：地缘政治冲突时（如 2022 年俄乌、2024 年中美关税），外资可能短期大规模撤离

```
【信号判断】
- 总量信号：[流入持续 / 拉锯 / 流出加速]
- 风格信号：[消费 + 医药为主 / 切向科技成长 / 切向高股息]
- 短期影响：[利好 / 中性 / 利空]
- 中线启示：[关注外资抱团方向 / 关注被减持的潜在压力]

【交易日历】
- 下次 MSCI 调样窗口：2026-XX
- 港股通假期：2026-XX
```

## 重要提示

- **不要单看一日数据**：北向资金日内波动大，看 5 日、20 日趋势更稳
- **结合公募持仓**：外资持股变动和公募持仓季报对照，判断是否一致
- **配合估值看**：北向减持低估值股票 = 风格切换；减持高估值股票 = 兑现收益
- **MSCI / FTSE 季度调样必查**：被动资金提前布局，会推动价格异动
- **MOM 指数 / Russell 指数也有影响**：但量级远小于 MSCI
- **个股层面的"持股占比"比"净买入金额"更有意义**：避免市值大的股票看绝对金额误导
