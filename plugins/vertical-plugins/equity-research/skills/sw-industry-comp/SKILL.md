# A 股申万行业成分股对比

## 什么是申万行业分类

申万行业分类（Shenwan Industry Classification, SW）是中国 A 股市场最广泛使用的行业分类标准，由申万宏源研究所维护，分为：

- **一级行业**：31 个（如食品饮料、电子、电力设备、医药生物）
- **二级行业**：134 个（如食品饮料下分白酒、啤酒、调味发酵品等）
- **三级行业**：358 个（更细分，如白酒下分高端白酒、次高端白酒、其他白酒）

**为什么不用 GICS / 中信行业 / 证监会行业？**
- GICS（标普全球行业分类）：海外标准，对 A 股本土行业（如白酒、中药）覆盖不准
- 中信行业：和申万差异不大，但卖方研究主流是申万
- 证监会行业：法定分类但过于粗放（如所有制造业归一类）

申万分类的优势：颗粒度合适、券商研报通用、数据库（Wind/Choice/AKShare）原生支持。

## 工作流

### Step 1：行业定位

询问用户：
- 想分析的行业（按申万一级名称，如"白酒"或对应代码）
- 关注层级：一级（粗放对比） / 二级（中等） / 三级（细分赛道）
- 时点：当前 / 历史某一时点
- 排序维度：估值 / 盈利 / 成长 / 综合

### Step 2：拉取成分股

通过 AKShare MCP：

```python
# 申万一级行业成分股
ak.sw_index_first_info()  # 一级行业列表
ak.sw_index_third_info()  # 三级行业列表
ak.index_component_sw(symbol="801080")  # 食品饮料一级 成分股

# 申万行业指数行情
ak.index_realtime_sw(symbol="一级行业")
ak.index_hist_sw(symbol="801120", period="day")  # 食品饮料-白酒 二级
```

行业代码对照（部分高频）：
- 801010 农林牧渔 / 801030 化工 / 801050 有色金属
- 801080 电子 / 801120 食品饮料 / 801150 医药生物
- 801180 房地产 / 801200 商贸零售 / 801710 建筑材料
- 801730 电力设备 / 801750 计算机 / 801770 通信
- 801780 银行 / 801790 非银金融 / 801880 汽车

### Step 3：核心对比维度

**A. 估值维度（5 列）**
- PE（TTM）
- PE 历史 5 年分位（当前位置 vs 自身历史）
- PB（MRQ）
- PB 历史 5 年分位
- 股息率（TTM）

**B. 盈利能力（5 列）**
- ROE（TTM）
- 销售毛利率（TTM）
- 销售净利率（TTM）
- ROIC（TTM）
- 经营性现金流 / 净利润

**C. 成长性（4 列）**
- 营收增速（最新季度 YoY）
- 扣非归母增速（最新季度 YoY）
- 营收 3 年 CAGR
- 净利润 3 年 CAGR

**D. 财务质量（4 列）**
- 资产负债率
- 商誉 / 净资产
- 大股东质押率
- 应收账款周转天数

**E. 资金面（3 列）**
- 总市值（亿元）
- 流通市值（亿元）
- 北向持股占流通股比例

### Step 4：综合评分（行业内排序）

每个维度归一化到 0-100 分，按可定制权重综合：

```
综合得分 = 估值分（30%）+ 盈利分（25%）+ 成长分（20%）+ 质量分（15%）+ 资金分（10%）

估值分：PE / PB 分位低 → 高分；股息率高 → 加分
盈利分：ROE 高 → 高分（行业内排序）
成长分：营收 / 净利润增速高 → 高分
质量分：负债低、商誉少、质押少、应收周转快 → 高分
资金分：北向占比高 → 高分（外资认可）
```

### Step 5：龙头识别（双因子）

A 股行业龙头的标志：
- **市值前 3** + **行业市占率前 3** + **ROE 在行业前 30%**
- **公募基金重仓股名单出现** + **被申万指数纳入成分股权重前 10**
- **机构关注度高**（卖方研究覆盖券商数 > 15 家）

### Step 6：估值分位预警

对每个成分股给出估值历史分位提示：

| 当前估值分位 | 解读 |
|---|---|
| < 10% | 历史低位，关注是否价值陷阱 / 行业逻辑变化 |
| 10-30% | 偏低，关注催化剂 |
| 30-50% | 合理偏低 |
| 50-70% | 合理 |
| 70-90% | 偏高，关注业绩兑现能力 |
| > 90% | 历史高位，注意估值消化风险 |

## 重要提示

- **不要做跨行业对比**：申万一级之间业务模型差异巨大，PE / PB 不可比
- **二级 vs 三级选择**：二级覆盖 100+ 只时用三级，避免大行业里的子板块差异被掩盖
- **龙头不是永远的**：行业格局会变（如白酒五粮液 vs 茅台、家电美的 vs 格力的相对地位历史变化）
- **历史估值分位不是绝对参考**：行业逻辑变化会让分位失效（如教培行业 2021、地产 2023 之后历史分位无意义）
- **小市值警惕**：流通市值 < 50 亿的股票，估值数据容易被操纵，慎重对比
- **次新股剔除**：上市 < 1 年的次新股估值不稳定，单独看
- **ST 股剔除**：连续亏损或财务异常公司，不能纳入正常对比
- **业绩季更新**：财报披露后 1-2 周内重新跑数据，避免用过时财报排序
